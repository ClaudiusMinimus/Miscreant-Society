# Miscreant Society 1.21.1

Miscreant Society is a modpack created for my family’s SMP server. It’s a lightweight pack centered around the mods Create, Chipped, Farmer’s Delight, Paladin’s Furniture, and a few others. For players who prefer not to frequently update modpacks, Miscreant Society will only receive updates when absolutely necessary. Most client-side mods are disabled by default but can be enabled through the launcher settings.
